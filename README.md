# 云朵造屋社

面向约 6 岁儿童的盖房子关卡游戏。玩家对照目标卡，把材料放进 9×8 格子舞台；相似度严格超过 90% 即可过关。游戏也提供没有标准答案的自由创作模式。

## 运行

```bash
yarn install
yarn dev
```

浏览器打开终端显示的本地地址即可开始游戏。

## 部署

推送到 `main` 分支后，GitHub Actions 会自动测试、构建并部署到 GitHub Pages。

## 已实现

- 6 个递进关卡、关卡解锁和徽章奖励
- 实时相似度、严格大于 90% 的过关判定
- 点选放置、拖拽放置、替换、橡皮擦、撤销、清空和一块提示
- 自由创作、3 种天空主题、本地作品册
- 本地进度保存、轻量音效、键盘焦点和减少动画适配
- 桌面、平板和手机响应式布局

## 验证

```bash
yarn test
yarn build
```
